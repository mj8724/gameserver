## 平台与部署边界（r5）

- 生产目标平台 = **Windows 10 x64**（声明对象，ADR §1.6）；Linux/macOS 保持**未验证**，不得声称支持。
- M3–M6 实机动作在**隔离数据根**执行：证据标注「隔离数据根基线验收」，不使用生产可靠性表述。

## 顺序与不变量

- 严格 M3→M4→M5→M6；跨里程碑只允许预留扩展点，不允许提前实现。
- 统一门禁：gofmt（cmd internal tools）/ vet / test / test -race（Windows 无 gcc 时由 Ubuntu CI 承担）/ 交叉构建 / tidy / `m3-offline.sh`（M3 起）/ `m2-offline.sh`（回归不变式）/ CI 绿。
